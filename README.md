# 거울 던전: 전술 편성

림버스 컴퍼니 분위기의 브라우저 자동 전투 게임입니다. 인격을 영입하고 전장에 배치한 뒤 전투를 진행합니다.

## 실행

`index.html`을 VS Code Live Server 같은 로컬 웹 서버로 엽니다. 파일을 직접 `file://` 주소로 열지 마세요.

## 플레이

- 상점에서 인격을 영입하고 벤치에서 아군 진영으로 드래그해 배치합니다.
- 인격을 클릭하면 상태창을 볼 수 있습니다. 같은 인격 3개를 모으면 별 등급이 올라갑니다.
- 장비를 클릭하거나 인격에게 드래그해 장착합니다. 전투에서 승리하면 장비를 얻습니다.
- 작전 개시를 누르면 자동 전투가 시작됩니다. 게임이 끝나면 도달 단계가 기록됩니다.

## 계정과 순위

Supabase 설정 방법은 [SUPABASE_SETUP.md](SUPABASE_SETUP.md)를 참고하세요. 데이터베이스 테이블과 정책은 [`supabase/schema.sql`](supabase/schema.sql)에 있습니다.
