# 거울 던전: 전술 편성

림버스 컴퍼니 분위기의 브라우저 자동 전투 게임입니다. 인격을 영입하고 전장에 배치한 뒤 전투를 진행합니다.

## 실행

`index.html`을 VS Code Live Server 같은 로컬 웹 서버로 엽니다. 파일을 직접 `file://` 주소로 열지 마세요.

## 플레이

- 상점에서 인격을 영입하고 벤치에서 아군 진영으로 드래그해 배치합니다.
- 인격을 클릭하면 상태창을 볼 수 있습니다. 같은 인격 3개를 모으면 최대 4성까지 올라갑니다.
- 장비를 클릭하거나 인격에게 드래그해 장착합니다. 전투에서 승리하면 기본 장비를 얻습니다.
- 장비 보관함의 **조합** 버튼을 누르고 기본 장비 두 개를 차례로 선택하거나, 장비를 다른 장비 위에 드래그해 조합합니다. **레시피** 버튼에서 10가지 조합과 효과를 볼 수 있습니다.
- 작전 개시를 누르면 자동 전투가 시작됩니다. 게임이 끝나면 도달 단계가 기록됩니다.

## 2인·4인 온라인 대전

참가자가 각각 로그인한 뒤 한 사람이 **온라인 대전 → 2인 방 만들기** 또는 **4인 방 만들기**로 6자리 코드를 만들고 다른 사람에게 알려줍니다. 참가자는 **방 참가**에 코드를 입력합니다. 정원이 모이면 20초 동안 각자 인격을 영입·배치한 뒤 대전이 자동으로 시작됩니다. 전투가 끝나면 다음 라운드도 20초 뒤 시작됩니다. 4인 방에서는 매 라운드 두 경기씩 진행하고 대전 상대를 바꿉니다. 세 라운드마다 나머지 세 사람과 한 번씩 겨루며, 방에는 개인별 승수가 표시됩니다. 각 화면은 동일한 전투 규칙과 시드로 결과를 계산하므로 승패가 일치합니다. 방에 들어가면 진행 중인 1인 작전은 초기화되며, 방은 참가자들이 접속하는 동안 유지됩니다.

대전 동기화는 Supabase Realtime Presence와 Broadcast를 사용하며 추가 데이터베이스 테이블은 필요하지 않습니다. 대전 전투와 점수는 브라우저에서 계산하므로 공개 경쟁의 부정 행위를 막으려면 서버 검증이 추가로 필요합니다.
